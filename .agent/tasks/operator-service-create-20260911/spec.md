# Добавление услуги через Оператора

Одна команда текстом/голосом сохраняет услугу и цену, готовит отдельное подтверждение Google и отслеживаемую ручную задачу для остальных подключённых карт. Общий путь Telegram, Mini App, web; права и журнал запросов сохраняются. Не создавать реальные услуги на Riderra в проверках.

Проверки: шесть входов, дубли, похожие названия, уточнения и отмена, валюта/цена, чужой бизнес, изменённый preview, повтор подтверждения, Google без доступа/с изменённым списком/с ошибкой, сохранение существующих услуг, отдельная ручная задача и завершение. Реальную запись Google не считать проверенной без её выполнения с подтверждением пользователя.

Google: https://developers.google.com/my-business/content/services — canModifyServiceList, readMask, patch updateMask=serviceItems, замена полного списка. Перед записью сравнить snapshot; после записи перечитать. Не обещать немедленное появление на публичной карте.
