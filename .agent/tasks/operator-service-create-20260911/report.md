# Добавление услуг через Оператора — 11 сентября 2026

Реализовано: общий инструмент создания услуги с названием, ценой, валютой, необязательными описанием и категорией; проверка владельца/управляющего и тарифа; блокировка бизнеса, журнал запроса и проверка похожих названий. Уточнение сохраняется в канальном диалоге. Явное создание отдельной услуги и выбор изменения существующей цены поддержаны; последнее требует подтверждения и меняет только LocalOS.

После создания подготовлен отдельный Google preview: подключённая карточка, canModifyServiceList, категория, цена, snapshot списка. Подтверждение связано с сохранённой услугой и версией preview; срок/повторы/доступ проверяются общим механизмом. Google PATCH использует только updateMask=serviceItems, сохраняет прочитанный список и дополняет его; после записи выполняется GET. Повтор после неопределённого результата сверяет уже имеющуюся услугу, не добавляет её повторно. Изменение исходного списка блокирует старое подтверждение. Google может менять публичную карточку с задержкой; ответ API не назван доказательством публичного размещения.

Для подключённых Яндекс/2ГИС либо существующего yandex_url создаётся обычная journey action, назначенная единственному активному управляющему. Если его нет/несколько, задача остаётся без назначения с явным объяснением. Можно назначить выбранного управляющего через Оператора; завершение доступно через существующую задачу или явное сообщение о выполнении. Уведомления используют существующую очередь и настройки получателя; отключённые уведомления не объявляются отправленными. При отзыве членства выдача из очереди запрещена. Ошибка Google не откатывает услугу; повтор Google обрабатывается отдельно.
