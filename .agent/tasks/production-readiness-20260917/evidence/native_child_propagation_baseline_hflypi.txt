Baseline before the child-propagation patch (read-only source inspection).

`tests/conftest.py::_run_flask_db_upgrade` creates an explicit environment and
sets PYTHONPATH to `<project>/src:<project>`.  The draft guard had no
`_patch_subprocess`, `_child_environment`, or other child-env injection path.
Therefore Python subprocesses whose callers construct smaller explicit envs
could omit the guard's required Docker/Testcontainers configuration and exit
78 during sitecustomize initialization.

This is a harness-isolation gap, not a product defect.  No Python, Docker,
database, network, or project test was run for this baseline capture.
