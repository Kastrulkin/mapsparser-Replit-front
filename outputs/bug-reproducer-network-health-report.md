## Root cause

The single-business branch bypassed the current-snapshot query and counted only source=yandex_business without the is_current filter.

## Approved fix

Load _network_attention_rows once and use its current unanswered-review count for both single-business and network responses.

**Why this is causal:** The corrected branch now reads the exact current-snapshot value that previously appeared only in attention rows.
