# Продолжение контент-плана голосом и текстом

Команда: «12 го заканчивается подготовленный контент план — нужен следующий, сделай, старый не удаляй».

Создание через общий Operator передаёт признак продолжения и идентификатор запроса. Новый план начинается после последней фактической даты записи предыдущего плана (с учётом переносов), сохраняет предшественника и каналы. Указанная пользователем дата окончания проверяется; конфликт или отсутствие исходного плана требуют уточнения. Старые записи не обновляются и не удаляются.

Генератор исключает совпадающие нормализованные названия тем предыдущего плана и не повторяет темы для заполнения количества. Это не семантическая гарантия отсутствия похожих идей. При недостатке тем создаётся меньше записей, при полном отсутствии — уточнение. Создаётся календарь тем; готовые тексты и публикации остаются отдельными действиями.

Идемпотентность: блокировка создания по бизнесу, сохранённый request_id в metadata плана, возврат уже созданного плана при восстановлении после сбоя до записи chat journal. Старые клиенты без request_id совместимы.
