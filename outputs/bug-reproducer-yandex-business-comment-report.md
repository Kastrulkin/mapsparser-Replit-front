## Root cause

The owner-response extractor accepted legacy response keys but omitted Yandex's current businessComment and business_comment keys.

## Approved fix

Added businessComment and business_comment to the existing response-key fallback chain.

**Why this is causal:** The existing normalization logic already handles the object shape; making the current keys reachable preserves the response text, date and has_response flag.
