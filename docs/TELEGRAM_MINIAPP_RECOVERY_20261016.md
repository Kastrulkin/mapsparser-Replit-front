# Восстановление запуска Telegram Mini App — 16.10.2026

**Результат:** FIX_PROVEN для ошибки HTTP 500 при подписанном bootstrap в настольном Telegram. Повторная проверка телефона пользователем ещё не выполнена.

## Причина и воспроизведение

Публичная страница `/telegram/control` отвечала 200, но реальный `POST /api/operator/telegram/bootstrap` падал с NameError: `MOBILE_NAVIGATION_CAPABILITIES` отсутствовала в развёрнутом `operator_api.py`. Также отсутствовали `MOBILE_MODULE_CAPABILITIES` и `MOBILE_ACTION_CAPABILITIES`, используемые соседними модулями и проверкой действий. Предыдущий тест MAX bootstrap подменял `_mobile_navigation`, поэтому не выявил потерю этих определений при подготовке выпуска.

Регрессионный тест использует настоящую проверку подписи Telegram, настоящую навигацию и тарифные capabilities; подменяет только источники данных и выдачу сессии. Четыре варианта business/network/platform и соседняя проверка write-capabilities до исправления завершились 5 failures с тем же NameError.

## Исправление

В одном runtime-файле восстановлены три таблицы соответствия разделов/действий действующим capabilities из канонического рабочего кода. Права не ослаблялись. Удалена подмена навигации из MAX bootstrap test.

Исходный SHA-256: `cd89db97ffa2642c0e4cd348ab2792a0f3f4d96de72c270194588d991690db60`.
Исправленный SHA-256: `6288c7008b86179373726183f5d0cb6a832b00b82ab101279f40cb35febbf8ca`.

Перед заменой серверный хеш проверен; файл сохранён в `/opt/seo-app/backups/telegram-bootstrap-20261016/operator_api.before.py`. Обновлён только этот файл, перезапущен только app. База, схема, настройки бота, frontend и параллельные исходники не менялись.
