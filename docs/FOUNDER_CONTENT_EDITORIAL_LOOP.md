# Утренний редакторский контур LocalOS

## Назначение

Контур готовит один авторский Telegram-черновик о подтверждённом изменении LocalOS и присылает его суперадмину утром. Он ничего не публикует и не отправляет в публичный канал.

## Поток

1. После значимого production-релиза агент или оператор создаёт структурированный `founder_content_brief`.
2. Worker в утреннее окно выбирает один brief с максимальным приоритетом.
3. К brief подбираются минимум три B2B-публикации из двух независимых источников с обязательным фильтром `corpus_tag=telegram_b2b`.
4. Генератор использует продуктовый brief как единственный источник фактов о LocalOS, а B2B-корпус — только как теоретическую основу.
5. Текст проходит human-language gate и проверку длинных совпадений с исходными публикациями.
6. Бот присылает черновик суперадмину и сохраняет Telegram `message_id`.
7. Суперадмин отвечает на сообщение полной исправленной версией.
8. LocalOS сохраняет исходник, итог, word-level diff, edit ratio и редакторские признаки.
9. Последние пары `черновик → версия автора` добавляются в контекст следующих генераций.

Это preference learning по подтверждённым правкам, а не автоматический fine-tuning весов модели.

## Добавление продуктового brief

Dry-run:

```bash
python scripts/queue_founder_content_brief.py \
  --title "Обновили поиск партнёров" \
  --change "LocalOS теперь проверяет компанию, сигналы и подтверждения до подготовки письма" \
  --rationale "Сильный B2B-аутрич начинается с правильного выбора компании и момента" \
  --proof "Функция развёрнута и прошла production-проверку" \
  --source-ref "commit-or-task-reference"
```

Для записи добавить `--apply`. В production запись выполняется только после явного подтверждения пользователя.

## Runtime-флаги

- `FOUNDER_CONTENT_MORNING_ENABLED=false` — безопасный выключатель; включается отдельно после миграции и тестового запуска.
- `FOUNDER_CONTENT_MORNING_HOUR=9`
- `FOUNDER_CONTENT_MORNING_MINUTE=30`
- `FOUNDER_CONTENT_COOLDOWN_HOURS=36`
- `FOUNDER_CONTENT_SCAN_INTERVAL_SEC=60`

Часовой пояс фиксирован: `Europe/Moscow`.

## Хранение

- `founder_content_briefs` — подтверждённые темы и факты о продуктовых изменениях.
- `founder_content_drafts` — черновики, Telegram delivery state, исправленная версия и diff.
- `ailearningevents` — пары `draft_text/final_text` с capability `founder_content.post`.
- `userexamples` — подтверждённые авторские версии с `origin=approved_edit` и `platform=telegram`.

## Ограничения

- Нет автопубликации.
- Ответ должен быть Telegram reply на конкретный утренний черновик.
- Исправленная версия короче 100 символов не принимается как обучающий пример.
- B2B-корпус не становится источником фактов о LocalOS.
- Формулировки авторских каналов не копируются и не используются для имитации конкретного автора.
