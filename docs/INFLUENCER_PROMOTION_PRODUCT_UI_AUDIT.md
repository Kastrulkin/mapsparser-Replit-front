# UX-аудит: «Продвижение → Локальные авторы»

Статус: проверка реализации beta перед пилотом.

| Пользовательская задача | Риск до изменения | Решение | Проверка |
| --- | --- | --- | --- |
| Понять разницу между контентом, партнёрствами и инфлюенсерами | Новый сценарий мог перегрузить «Контент» | Отдельный hub «Продвижение» с двумя исходами: бизнес-партнёры и локальные авторы | Первый пользователь выбирает нужный сценарий по описанию результата |
| Начать поиск без знания внутренней модели данных | Равновесные таблицы профилей, источников и лидов не дают точки входа | Экран начинается с brief: город, район, аудитория, услуга, формат и бюджет | Основная кнопка активируется после заполнения города |
| Понять, почему рекомендован автор | Непрозрачный рейтинг провоцирует выбор по подписчикам | Карточка показывает балл, локальные причины, источник и группу соответствия | Для каждого результата API возвращает score version, reasons и evidence |
| Безопасно перейти к коммуникации | Пользователь может принять подготовку за отправку | Условия утверждаются отдельно; интерфейс прямо сообщает, что подтверждение ничего не отправляет | API подготовки возвращает `external_messages_sent: 0` и запрещает действие до approval |
| Контролировать исполнение | Статусы кампании и публикации смешиваются | Кампании, коллаборации, материалы и результаты разделены по этапам | У коллаборации и каждого deliverable свой lifecycle status |
| Оценить результат без ложной атрибуции | Наблюдаемые просмотры могут выглядеть как доказанная выручка | Метрики содержат source/confidence; выручка подписана как подтверждённая | В интерфейсе отображается disclaimer и отдельные расчётные показатели |

## Проверенные состояния

- Нет выбранного бизнеса: понятное приглашение выбрать бизнес.
- Feature недоступна: возврат в действующие «Партнёрства».
- Пустой поиск: объяснение первой операции и ожидаемого результата.
- Загрузка: стабильная область с индикатором без сдвига компоновки.
- Ошибка API: текстовый alert с сохранением заполненного brief.
- Пустые кампании и коллаборации: сценарный следующий шаг.
- Ручное подтверждение: внешние действия не маскируются под обычное сохранение.

## Остаточные риски пилота

- Качество shortlist зависит от покрытия подключённых публичных источников.
- Публичные метрики разных платформ несопоставимы без нормализации и достаточного числа snapshots.
- Автоматическое обнаружение новых источников и массовый импорт отложены; в пилоте эти шаги требуют ручной работы.
- До production rollout нужен browser-проход на реальных данных пилотного бизнеса, проверка клавиатурной навигации и контрастности в используемой теме.
