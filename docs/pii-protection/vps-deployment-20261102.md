## Восстановление и следующий этап

До замены файлов сохранены точные исходники, права и манифест отката в
`/opt/seo-app/backups/pii-disabled-20261102T140039Z`, каталог защищён `.keep`.
Управляющий скрипт и журналы находятся в `/opt/seo-app/.deploy/pii-20261102-v1`.
Автоматический откат при ошибке сверяет текущие SHA перед восстановлением, чтобы
не затереть параллельные изменения. Откат не потребовался.

Рабочее включение требует отдельной настройки runtime и ограниченной группы задач.
Текущий процессный runtime создаёт NLP engine в каждом consumer; модели ещё не
установлены в рабочие app images. Для этого VPS следующий этап — общий процесс
распознавания с одной NLP-полосой, отдельные Redis-доступ/ключ и проверенная серверная
разметка публичного контекста. Неподдержанные legacy/image/embedding маршруты при
включении продолжают блокироваться. Выкладка с выключенным флагом не означает,
что рабочий трафик уже псевдонимизируется.

Ни одного запроса к внешнему LLM в ходе тестов не выполнялось. Образ собирался из
публичных HTTPS-зависимостей с ограничением 0.5 CPU / 768 MiB; из-за недоступности
репозиториев из Docker bridge установка выполнялась через host network.
Сам синтетический прогон оставался network=none. Исправлен формат constraints для
моделей, их версии сохранены, SHA-256 wheel закреплены в requirements.
