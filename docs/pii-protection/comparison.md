# Сравнение кандидатов

Статус: `internal`. Обновлено 02.11.2026: повторный [Linux/Redis-пилот](benchmark.md).
Первый срез — [01.11.2026](benchmark-20261101.md). Результаты
относятся к [фиксированным 200 сценариям](../../tests/fixtures/pii/synthetic_200.jsonl).

| Свойство | piighost + Presidio | Preserve |
|---|---|---|
| Версии пакетов | 2.1.1 + 2.2.366 | preserve-pii 0.6.2 |
| Лицензия основного кода | MIT | MIT |
| NLP в сравнении | spaCy 3.8.18, en_core_web_sm / ru_core_news_sm 3.8.0 | Те же модели |
| Языковая маршрутизация | Кириллица → RU; остальные → EN | Та же |
| Обратимая подмена | Настоящий AnonymizationPipeline и его deanonymize | Настоящий Scrubber и PlaceholderMap.restore |
| Streaming | Есть upstream-механизм, проверен независимый ограниченный декодер LocalOS | Есть upstream-механизм; собственный HTTP proxy не интегрируется |
| Хранение в LocalOS | Общий encrypted Redis + HMAC scope + TTL | Для сравнения тот же контракт мог бы использовать тот же store |
| Tool calls | Нужна серверная граница восстановления LocalOS | Готовый proxy восстанавливает аргументы без allowlist LocalOS |
| Постоянная локальная LLM | Не используется | Не используется |
| Большой словарь имён | Не используется | names-dataset установлен как зависимость, но scorer выключен |
| Итог выбора | Выбран: после исправлений одинаковый recall, меньше лишних детекций и значительно меньше задержка | Оставлен заменяемым тестовым кандидатом |

Выбор не означает, что стандартные настройки piighost/Presidio качественнее
стандартных настроек Preserve: на этом наборе native Preserve защищает больше
значений. Адаптированный вариант LocalOS выигрывает по времени и числу лишних
детекций. Новые правила контекстных имён и одинаковые серверные публичные
диапазоны применяются к обоим кандидатам. Производительность, ошибки
и качество каждого профиля опубликованы отдельно в [benchmark.md](benchmark.md).

## Что действительно проверено

- Исходники адаптеров, конфигурации и mapping, а не только README.
- Наличие MIT в LICENSE обоих upstream-проектов и Presidio; названия/версии
  установленных пакетов присутствуют в каждом JSON-результате.
- Реальные Python-библиотеки работают локально, без сетевых детекторов.
- Оба кандидата получают одинаковый корпус и одинаковые правила LocalOS.
- Native-восстановление выполняется методами самих библиотек.
- CPU/RAM замерены в отдельных процессах; параллельная очередь имеет четыре
  клиента и одну полосу NLP, без неконтролируемого размножения моделей.

## Ограничения сравнения

Preserve проверяется в лёгком профиле: AGGRESSIVE, NER включён, name scorer,
normalcy scanner и local LLM выключены. Это не замер всех режимов Preserve.
Presidio использует compact RU/EN, а не стандартный большой EN-пакет. Поддержка
стран/форматов не означает полноценную поддержку языка. Турецкая, немецкая,
арабская и смешанная речь проверены, но отдельные обученные модели для них не
устанавливались. Суффикс `.invalid` и идентификационные значения намеренно
синтетические: проверка действительности реквизита не должна быть единственной
защитой от отправки похожего чувствительного значения.

200 сценариев получены из 20 форм и 10 языковых/форматных вариантов, а не из
200 независимо собранных реальных разговоров. Семейства имён и реквизитов
повторяются. Это воспроизводимый стресс-пилот, не оценка качества в production.
