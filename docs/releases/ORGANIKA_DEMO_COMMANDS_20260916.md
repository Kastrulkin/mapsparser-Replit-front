# Проверенные команды для демонстрации Органики

Выберите «Органика». Проверки выполнены 16 сентября 2026. 105 сценариев проверены на развёрнутой серверной обработке с настоящей моделью; 48 дополнительных формулировок прошли повторно. Это не подтверждает доставку Telegram или работу микрофона конкретного телефона.

## Короткий показ

1. «Какой следующий пост запланирован?» — показывает сохранённый материал. Полный путь аудио → SpeechKit → ответ проверен на production для веба и Mini App.
2. «Покажи последний пост в контент-плане целиком» → «Переведи этот пост на английский язык, сохрани ссылку». Меняет черновик; публикации нет. Для показа используйте тестовый черновик, если существующий нельзя менять.
3. «Создай контент-план с 1 декабря 2026 на две недели, два поста в неделю, всего четыре поста». Проверенные даты: 1, 4, 8, 11 декабря.
4. «Пожелание клиента: получать имя мастера и рекомендации по подготовке заранее. Передай администратору». Запись появляется в «Рабочий журнал → На разбор». До назначения права администратору её разбирает владелец.
5. «Сегодня десять чеков, два с допродажей, выручка 350 рублей». Показывает финансовое подтверждение; без подтверждения показатели не меняются. Для демонстрации не подтверждайте вымышленные суммы.
6. «Сколько отзывов осталось без ответа?» — читает текущие данные без генерации ответов.

## Ограничения показа

- Telegram-бот: соединение через действующий прокси не восстановлено. Не использовать как основной канал демонстрации до успешного реального приёма.
- Реальные iOS/Android пока не проверены; серверный аудиотест использовал синтезированную речь.
- В Органике отсутствуют записи визитов, мастера и утверждённые связки допродаж. Персональную утреннюю планёрку по расписанию показывать нельзя до наполнения этих данных.
- Месячная сумма не сохраняется как дневной итог: Оператор объясняет ограничение и направляет к импорту.
- Сложное составное правило рекомендаций может потребовать уточнения. Оно не применяется частично и молча.
