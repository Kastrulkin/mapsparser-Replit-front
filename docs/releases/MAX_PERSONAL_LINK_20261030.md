# Персональная ссылка подключения MAX

Статус: available, 30 октября 2026.

Ссылка `https://max.ru/<bot>?startapp=connect_<one-time-code>` открывает
мини-приложение с готовыми данными подключения. Пользователь нажимает
«Подключить аккаунт», не копируя код. Код не показывается отдельным полем.
Подтверждение остаётся явным; открытие ссылки не связывает аккаунт автоматически.

Код извлекается из подписанного `start_param` MAX, с резервным чтением
`WebAppStartParam`. Формат строго проверяется. Используется существующий
`POST /api/max/link`: подписанная личность MAX, одноразовость и срок 10 минут
не изменены. При истёкшей ссылке предлагается запросить новую.
Персональная ссылка является секретом и предназначена только получателю.

Приглашение подключения не интерпретируется как токен клиентского пути.
Обычный ручной ввод кода сохранён. Если аккаунт MAX уже подключён,
существующее поведение bootstrap не меняется; другой аккаунт не подменяется.
