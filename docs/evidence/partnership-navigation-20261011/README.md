# Исправление ухода со страницы «Партнёрства»

Пользователь сообщил, что при переходе к инфлюенсерам, среднему чеку и ИИ-сотрудникам остаётся экран партнёрств.

В опубликованной исходной версии `ed78bab13` список видимых черновиков вычислялся заново при каждом рендере. Эффект очищал выбор через `filter`, каждый раз записывая новый массив, включая пустой. Это создавало непрерывный цикл обновлений без изменения данных и мешало навигации.

Регрессионный тест монтирует настоящую страницу с незавершёнными запросами. Ограничение числа commit-фаз прерывает ошибочный цикл, чтобы тест не зависал. До исправления все четыре сценария завершились ошибкой `Partnerships keeps rendering without any data or user change`. После исправления состояние возвращает прежний массив, если очистка ничего не изменила. Очистка недоступных черновиков сохранена.

Проверки: четыре регрессионных сценария (стабильный пустой выбор и три перехода без ожидания данных); вместе с тестами реестра и меню — 32 теста прошли. Данные, API, доступы и действия с черновиками не изменяются.

Сборка, проверка типов относительно исходной версии, product UI guard, целостность сборки и проверка опубликованных переходов фиксируются в завершающем протоколе ниже.
