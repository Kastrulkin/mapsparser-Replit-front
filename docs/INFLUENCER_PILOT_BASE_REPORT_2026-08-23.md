## Как собиралась база

- Telegram: TGStat проверен, но расширенный массовый поиск без входа ограничен. Для discovery использован Telemetr; каждый оставленный канал проверен на оригинальной `t.me`-странице.
- Instagram, Threads и TikTok связаны по handle. Threads и TikTok учитываются как каналы того же автора, а не новые люди.
- YouTube/Shorts: канал оставался в базе, если открыт оригинальный профиль и есть конкретное видео с явной привязкой к городу.
- VK: кандидаты взяты из городских редакционных и рекламных каталогов, затем открыта их оригинальная VK-страница.
- Яндекс Карты и 2ГИС: пройдены как `review_only`. Авторы отзывов не попадают в аутрич-базу без открытого профессионального контакта.
- Сайты/поиск: городские медиа и подборки использованы как discovery/evidence, но не дублируют уже найденный социальный профиль.

## Оценка

Каждая сущность получила предварительную оценку 0–100 по пяти признакам: качество локального evidence, размер аудитории, публичная досягаемость, качество первоисточника и мультиканальность. Привязка к пяти бизнесам — только гипотеза по тематике публичного контента; она требует ручного review.

## Следующий проход

1. Для каждого бизнеса выбрать 20–30 кандидатов с максимальным тематическим fit.
2. Вручную проверить последние 10–20 публикаций, долю нужного города в аудитории, brand safety, реальную досягаемость и прошлые интеграции.
3. Разделить офферы: оплата, бартер, совместное событие/продукт и affiliate/промокод.
4. Только после этого показать import preview и попросить явное подтверждение выбора. Импорт не разрешает отправку.
