# Демо LocalOS: соответствие действующему меню

Дата: 12 октября 2026. Статус: локальная реализация; production не обновлён.

## Задача пользователя

Новый владелец бизнеса должен понять, с чего начать, где выполняется работа и где посмотреть подтверждённый результат. Демо показывает возможности сервиса и явно обозначает ограничения учебного режима.

## Изменения

- Экскурсия версии 7 начинается с «Сегодня» и следует каноническому меню из `frontend/src/lib/workNavigation.ts`: ежедневная работа, шесть направлений, контроль, служебная область.
- 47 шагов охватывают также «Инфлюенсеров», «Средний чек», «Автоматизацию», «Ещё», «Пути роста», журнал и знания внутри «Бизнес и команда».
- Подписи больше не обещают отправку при переходе, рост бизнеса от настройки, полную историю или фиксированное количество услуг. Подготовка, проверка и подтверждение различаются.
- Изменённые подсказки доступны на 12 языках. Названия меню и групп берутся из общего реестра.
- Прогресс старых версий не переносит пользователя в удалённый шаг и не скрывает новую экскурсию. Сервер сохраняет версию старого клиента отдельно; миграция БД не требуется.
- В демо используется только разрешённый учебный бизнес: сетевой родитель не превращает запрос в недоступный сетевой отчёт. Переключатель не предлагает недоступные филиалы. Обычный сетевой контекст сохранён.
- Знания показаны отдельным локализованным примером без чтения приватного API, сохранения или скачивания документов. Права публичного демо не расширены.
- Чат явно доступен для просмотра: поле ввода, отправка, голосовые сообщения и вложения отключены. Реальные поручения доступны в собственном бизнесе.
- Мобильная кнопка продолжения экскурсии не перекрывает «Меню». Подсветка учитывает позднее появление экрана; устаревшие callbacks не подсвечивают предыдущий шаг. Запись событий не задерживает переходы.
- В учебной автоматизации удалены неработающие вкладки, обозначено отсутствие изменений компании; таймер симуляции очищается при смене задания.

## Техническая проверка

Результаты и скриншоты сохранены в `.agent/tasks/demo-navigation-20261012/`.

- Целевые frontend-тесты: 122 успешно. Проверены версия прогресса, порядок меню, локализации, запуск демо, безопасный бизнес-контекст, пример знаний, чат без отправки и переход при зависшей записи события.
- Целевые тесты API: 16 успешно. Один тест регистрации маршрутов через весь `main` исключён: в отдельном Python-окружении отсутствует Playwright, необходимый импортируемому парсеру. Это ограничение среды; полный запуск приложения этим тестом не подтверждён.
- Проверка типов, обе frontend-сборки, product UI guard и проверка целостности сборки — результаты в приложенных логах.
- Полный маршрут экскурсии пройден в браузере на локальной сборке с публичными демо-данными. Запись прогресса и событий при проверке обработана локально; внешние действия компании не выполнялись.
- Проверены 390, 768 и 1280 пикселей, отсутствие горизонтального переполнения, мобильное меню, пауза/продолжение, клавиатурное переключение вкладок знаний и видимый фокус.

## Ограничения и выпуск

В мобильном Sheet остаётся существующее предупреждение Radix об отсутствующем описании диалога. Новых ошибок runtime при чистой загрузке не обнаружено. Исследование с пользователями не проводилось.

Рабочая копия содержит посторонние изменения. `task-changes.patch` и `manifest.json` выделяют изменения этой задачи относительно снимка до начала работ; временная сборка всей рабочей копии не является изолированным production-набором. Перед выпуском необходимо применить этот набор к актуальной релизной базе и повторить проверки. Коммит, push и deploy для этой задачи пока не выполнены.

Выпуск затрагивает фронтенд и `src/api/guided_tour_api.py`. Новые таблицы, миграции, изменения закрытых документов и расширение доступа не требуются.
