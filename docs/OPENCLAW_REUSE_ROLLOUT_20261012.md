# OpenClaw: ограниченный пилот чтения сайта, 12 октября 2026

Статус: `beta`, сквозная приёмка не завершена.

## Проверенная граница

LocalOS сохраняет права, планы, версии, утверждения, кредиты, расписания,
квитанции и историю. Его ActionOrchestrator не является удалённым OpenClaw.
Изолированный compiled-runtime не получает сеть или секреты.

Удалённый OpenClaw версии 2026.2.1 не обновлялся. Переиспользован штатный
`web_fetch` через loopback `/tools/invoke` профиля LocalOS. Тонкий мост не
реализует новый браузер: он проверяет аутентификацию и область, вызывает только
фиксированный инструмент и возвращает ограниченный непроверенный материал.
Firecrawl должен быть явно выключен; платный резервный маршрут не запускается.

| Функция | Решение и текущая проверка |
| --- | --- |
| Чтение публичного сайта | OpenClaw `web_fetch`, проверено на example.com и raschyoska.ru; пилот только Энгельса |
| Поиск Tavily / Exa / Яндекс | Сохранены действующие адаптеры LocalOS; провайдер и стоимость не менялись |
| Пять действий существующего outreach-моста | Старый каталог сохранён; список имён не доказывает готовность исполнения всех действий |
| Интерактивный браузер / внешние аккаунты | В этот пилот не подключены; эквивалентность не доказана |
| Удалённое планирование | Проверенного структурированного контракта нет; оставлен планировщик LocalOS |
| Передача контента / Telegram / расписания | Не переносились, квитанции и настройки не менялись |

Меню и Operator используют общий `generate_draft_for_plan_item`. Новая ветка
встроена в него, а не в отдельный генератор или реестр подключений. Это не
доказательство готовности произвольного browser-use шага автоматизации: старый
реестр маршрутов сохраняется, выбор ссылки на OpenClaw требует свежей проверки,
но сквозная автоматизация чтения сайта отдельно не принята.

## Что ещё не принято

После восстановления оплаченного лимита выбранного ИИ нужно получить один
успешный черновик в меню, пройти тот же путь из чата и проверить повтор без
дубликата/нового списания. Не подключать другого платного провайдера автоматически.
Полный URL и время чтения сохранены в метаданных, но существующая карточка
источников не показывает этот provenance отдельным пользовательским блоком.
Это остаётся интерфейсным ограничением, а не подтверждённой готовностью.

Проверка инструмента действует 24 часа, затем fail-closed. Для продолжения пилота
запустить существующий `verify_web_read.py` на OpenClaw из
`/root/openclaw_runtime`: он обновляет verified_at только после успешной проверки.
Отдельный планировщик проверки не создавался. Дублирующие адаптеры не удалять до
успешной приёмки и проверки оставшихся вызовов.

Также обнаружен старый неверный индикатор создания плана: UI показывает 32
карточки при фактических 4. Дополнительных 32 генераций не было. Этот дефект не
исправлялся в backend-релизе, frontend сохранён без изменений.

## Точечный откат

источники/историю/квитанции не удалять. При полном откате восстановить только
затронутые файлы из `/opt/seo-app/backups/openclaw-content-20261012T081201Z`,
предварительно сверив, что после выкладки их не изменял другой релиз; новый reader
можно оставить неиспользуемым. Все серверные команды начинать с `cd /opt/seo-app`.
Не откатывать весь source tree, frontend, данные или расписания.
