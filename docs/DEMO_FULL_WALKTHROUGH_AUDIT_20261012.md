# Полное прохождение production-демо LocalOS — 12 октября 2026

Статус: проверка завершена; UX-приёмка не пройдена. Исправления по этому аудиту не внедрялись.

## Что проверено

Новый пользователь открывает `/demo`, узнаёт возможности сервиса, проходит маршрут и пробует открыть обещанную работу. Успех: подсказка соответствует фактическому экрану, действие имеет понятное последствие, переход приводит к нужному материалу, демо явно отделено от реальных действий.

На `https://localos.pro` просмотрены приветствие и все шаги 2–47 версии 7, включая финальное завершение. После блокировки перехода потребовалась перезагрузка; поэтому это не беспрепятственное прохождение. Отдельно открыты ссылки из «Ещё», цифровая комната, предложение допродажи, вкладки знаний, главный следующий шаг «Сегодня», учебный запуск и проверка автоматизации. Проверены пауза, продолжение, повторное начало, сохранение шага после перезагрузки и мобильное меню.

Основной маршрут — 1280 px. Дополнительные проверки — 390 и 768 px, с проверкой фактического `innerWidth`. На этих ширинах проверялись избранные состояния, а не весь маршрут заново. В проверенных состояниях горизонтального переполнения не найдено. Enter раскрывает направление результатов; мобильное меню закрывается Escape. Фокус подсказки виден в дереве доступности.

Проверенная сборка: `/assets/index-BIeAQ9i2.js`, CSS `/assets/index-CofxSjTH.css`. Работа велась с учебным бизнесом «Рога и копыта», без публикаций, отправок, оплаты, загрузки документов или изменения данных компании. Учебный запуск автоматизации менял только демонстрационное состояние.

Это экспертное прохождение, а не исследование с пятью представителями аудитории. Исследование остаётся незавершённым. Новая сборка и технические тесты не запускались: продуктовый код в рамках аудита не менялся.

## Что уже работает

- Приветствие перечисляет нынешние шесть направлений и объясняет два способа управления; кнопка старта читается на телефоне.
- Меню содержит прямые рабочие направления, «Ещё» не повторяет их.
- Вкладки карт переключаются; есть учебная услуга, поисковая фраза, новость и пример конкурента. Несколько счётчиков сначала загружаются — их промежуточные нули не трактовались как окончательные данные.
- Контент показывает четыре состояния подготовки, сохранения и проверки, явно предупреждая об учебных данных.
- Средний чек после восстановления навигации показывает понятный пакет «Стрижка собак + уход за лапами» и раскрывает фразу для команды.
- Вкладки характеристик, правил и документов открываются без закрытых файлов.
- Результаты показывают общий список направлений; раскрытие с клавиатуры работает. Отсутствие датированных этапов объясняется корректно.
- Пауза, продолжение, повторное начало и сохранение шага после перезагрузки работают; оговорка — зависание содержимого после партнёрств распространяется и на повторное начало.
- Финальное завершение доводит прогресс до 100%; повторное открытие обучения доступно. Регистрация и платежи не выполнялись.

## Порядок исправления

1. Устранить зависание после партнёрств и проверить целевые экраны без перезагрузки.
2. Исправить главный переход «Сегодня» и безопасно наполнить инфлюенсеров/журнал учебными данными.
3. Сделать настоящую проверку учебных черновиков, не считать открытие подтверждением.
4. Синхронизировать подсказки с рабочими действиями и ручной навигацией; согласовать факты и названия.
5. Проверить финансовые состояния и границу демо в цифровой комнате; затем повторить весь маршрут и мобильные сценарии.

Не увеличивать серверные права демо на реальные сведения, не добавлять реальную публикацию или отправку. Формулировку «все переходы работают» можно использовать только после повторного прохождения без восстановительных перезагрузок.
