# Mini App: ежедневная навигация

## Задача экрана

Владелец открывает Mini App, чтобы за несколько секунд понять состояние бизнеса, увидеть работу ЛокалОС и перейти к одному следующему действию.

## Изменение модели

| Раньше | Теперь |
| --- | --- |
| Нижнее меню повторяет внутренние разделы: задачи, отзывы и инструменты | Нижнее меню повторяет день владельца: `Сегодня`, `В работе`, `Прогресс`, `Оператор`, `Развитие` |
| Раздел `Ещё` — равнозначная сетка функций | `Развитие` группирует возможности по результатам: клиенты из карт, контент без рутины, партнёры, выручка и регулярная работа |
| Первый запуск сразу открывает рабочий интерфейс без объяснения | Однократное знакомство объясняет результат продукта, поручения, приоритет, выбор бизнеса и прогресс |
| Отзывы занимают постоянное место в нижнем меню | Отзывы открываются из приоритетной задачи, уведомления, очереди работы и сценария `Больше клиентов из карт` |
| Прогресс спрятан во втором слое | Прогресс становится основным ежедневным разделом для business/network scope |

## Первый слой

Пользователь должен сразу получить четыре ответа:

1. `Сегодня` — что произошло, что делает ЛокалОС и что важнее всего.
2. `В работе` — где требуется решение, что выполняется и что уже готово.
3. `Прогресс` — какой путь уже пройден и что мешает следующему результату.
4. `Оператор` — как поручить нужный результат обычными словами.

## Второй слой

Карты, отзывы, контент, услуги, финансы, партнёрства, ИИ-сотрудники, источники и настройки остаются самостоятельными рабочими экранами. Они открываются из результата, задачи, уведомления, deep link или сгруппированного сценария в `Развитии`.

## Безопасность и состояния

- Capability manifest продолжает скрывать недоступные разделы.
- Platform scope не показывает `Прогресс`, если backend помечает его `hidden`.
- Deep links на отзывы и другие объекты сохраняют серверную проверку scope.
- Первое знакомство показывается один раз для Telegram-пользователя на устройстве и доступно повторно из `Развития`.
- Одиночному бизнесу не показывается обучающий шаг про выбор масштаба; сети показывается сценарий `сеть или точка`.

## Проверка

- Component tests: первое знакомство для одиночного бизнеса и сети.
- Component test: outcome-навигация и быстрый переход к отзывам.
- Router test: `Прогресс` открывается как primary destination.
- Production build и визуальная проверка на `360×800` и `393×852`.
