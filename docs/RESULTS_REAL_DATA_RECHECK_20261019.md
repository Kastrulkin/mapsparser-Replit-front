# «Результаты»: повторная проверка 19 октября 2026

Статус: исправления проверены локально; production-приёмка выполняется после выкладки.

Задача владельца: найти выполненную работу, открыть подтверждения и понять недостающие данные. Проверка выполнена в существующей авторизованной сессии на реальных данных доступной точки, затем на контрольных данных для ошибок и смены контекста. Публикации, отправки, настройки бизнеса и финансовые записи не изменялись.

## Подтверждённые проблемы и исправления

1. Сервер `/operator/progress` использует общий адаптер `build_mobile_progress`: `as_of` и `recent_results`. Страница читала только `generated_at` и `recent_achievements`. На реальных данных сводка сообщала о подтверждённых этапах, а ниже отображалась ложная пустота; время отчёта отсутствовало. Добавлено чтение обоих контрактов с сохранением приоритета прежних полей. Даты сортируются, недатированные записи не добавляются искусственно.
2. Переключатель точек менял собственную подпись при клике по точке, которой нет в списке бизнесов аккаунта. Родитель отклонял такой выбор, а старые результаты оставались под новым названием. Заголовок теперь определяется принятым контекстом; недоступные варианты имеют явное объяснение и не выбираются. Права не расширяются. Запоздавший ответ, в том числе после получения заголовков до чтения JSON, не заменяет сведения нового контекста.
3. При HTTP 404 страница сохраняла прежние частные результаты как при временной ошибке. Теперь 401/403/404 очищают сведения; временная ошибка по-прежнему сохраняет текущую сводку с повторной попыткой.

До изменений регрессионные тесты воспроизвели проблемы контракта, ложного переключения, позднего ответа и 404. После исправлений те же проверки проходят.

## Проверки

- 36 целевых frontend-тестов: результаты, оба контракта API, локализации, сеть, DOM-изменения, контекст кабинета, заголовок и переключатель.
- 9 тестов проверки выпуска. Проверка распознаёт актуальное название «Чат с LocalOS» и сохраняет совместимость с прежним. Удалённое отсутствие прямого входа по-прежнему отклоняет выпуск.
- Обе production-сборки, product UI guard и целостность assets проходят. Mocked cockpit из guard не запускался: стенд работает на другом порту.
- Полная проверка типов сохраняет 11 диагностик исходной версии (дубли старых компонентов и посторонний тест журнала). Новых диагностик нет; отдельный проект конфигурации сборки проходит.
- Локальный браузер: 390/768/1280 px без горизонтального переполнения, Enter раскрывает направление и сохраняет фокус. Проверены сохранение сводки при временной ошибке, очистка при 404 и восстановление с другим бизнесом. Консоль чистая.

Тесты прежней структуры обновлены для уже выпущенного названия «Результаты» и раскрываемых секций. Проверки не заменены проверкой только наличия страницы.

## Безопасность выпуска

Работа изолирована от грязной основной копии. Основа — сохранённые исходники текущего production; параллельное изменение трёх файлов чата и партнёрств обнаружено до публикации и сохранено. Выпуск проверяет отпечатки исходников и текущий entry перед заменой файлов. Каталог временной загрузки уникален для выпуска.

Публикуется frontend. Endpoint, серверные права, схема БД и производственные записи не меняются. Перед заменой сохраняется предыдущий frontend и затронутые исходники. Реальные скриншоты и необезличенные журналы остаются локально в `output/results-ux-20261019/`.

Исследование с пятью представителями аудитории не проводилось; этот проход не заменяет пользовательское исследование. Сеть и потеря доступа проверены контрольными сценариями, не расширением доступа реального аккаунта.
