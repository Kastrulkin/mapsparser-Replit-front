## Восстановление при проверках

Первые попытки автоматически откатывались: неверное ожидание заголовка кейсов в проверке, затем слишком ранняя единичная проверка сразу после HUP. Ожидание приведено к трём последовательным успешным ответам с ограничением времени и повтором финального HEAD. Итоговый релиз прошёл проверки.

Общий guard всей новой сборки кабинета сообщил об отличии текста партнёрского интерфейса в текущем workspace. Эта сборка кабинета не публиковалась: существующие основной index и ресурсы сохранены. Это не заявляется как успешная проверка всего содержимого dirty-tree.
