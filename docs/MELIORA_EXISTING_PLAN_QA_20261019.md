## Исправления и доказательства

**REPRODUCED → FIX_PROVEN:** привязка фото существовала в metadata/журнале выбора, но мобильный список её не выдавал, поэтому проверить фото рядом с текстом было нельзя. Добавлена выдача только допустимого asset ID и показ по явной кнопке. Приоритет у существующего журнала ручного выбора. Доступ ограничен собственной/родительской библиотекой; чужой бизнес, соседняя точка, исключённые фото и документы отфильтрованы. Полный metadata и storage credentials в мобильный ответ не передаются. Переиспользован существующий просмотр фото веб-кабинета, с сессией миниаппа вместо оставшегося dashboard token. Фото загружается только по нажатию, увеличение закрывается штатно. Подтверждено настоящим Telegram UI и HTTP200 приватного preview.

**REPRODUCED → FIX_PROVEN:** настройки компании позволяли менять поля во время PATCH; после ответа сервера дописанная история могла стереться. Два теста до исправления упали, два соседних прошли. Теперь на время запроса блокируются поля и уход из формы, после ошибки введённые данные остаются. Готовый план не переписывается. Проверка для Telegram и MAX, сохранение через реальный production API с тестовой историей намеренно не выполнялось.
